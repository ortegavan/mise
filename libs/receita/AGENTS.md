# receita

Domínio de receita culinária.

domain-logic é TypeScript puro: sem @angular/\*, sem rxjs, sem classe, sem inject(). Funções puras, tipo de retorno explícito, arrays readonly.

Duração é string ISO 8601 ('PT1H30M'), nunca número de minutos.

Todo comportamento novo entra com teste Vitest no mesmo commit.
